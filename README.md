# ProofPilot — public website

The public ProofPilot website: Home, Sign in, Support, Privacy and Terms.
The page copy describes only capabilities that actually exist in the ProofPilot
application; unsupported claims (automatic reminders, household sharing,
automatic claim submission, guaranteed AI extraction, cloud document backup,
self-service account deletion) are deliberately not advertised.
